# 基于层次分析法（$AHP$）的笔记本电脑选购决策模型

## 1. 决策问题的层次结构模型构建

根据决策目标，我们将问题自上而下分为三个层次：目标层（O）、准则层（C）和方案层（P）。为了更全面地评估，我们在原题“价格、外观、配置”的基础上，拓展了“续航散热”和“售后品牌”两个因素。

- **目标层 (O)**：选择最合适的笔记本电脑。
- **准则层 (C)**：
  - $C_1$：价格（购机预算及性价比）
  - $C_2$：硬件配置（CPU、显卡、内存、硬盘等核心性能）
  - $C_3$：外观与便携性（重量、厚度、机身材质、屏幕素质）
  - $C_4$：续航与散热（电池容量、能效比、散热模组设计）
  - $C_5$：售后与品牌（品牌口碑、保修政策、线下服务网点、广告）
- **方案层 (P)**：假设有三款备选机型（实际应用中可替换为具体型号）：
  - $P_1$：性能导向型（如：某品牌游戏本，配置高，偏重）
  - $P_2$：便携办公型（如：某品牌轻薄本，续航好，轻便）
  - $P_3$：均衡全能型（如：某品牌全能本，各项居中）

## 2. 层次分析法（$AHP$）的理论框架与数学推导

层次分析法（Analytic Hierarchy Process, $AHP$）是一种将复杂决策系统的定性认知转化为客观定量数学权重的多准则决策方法。本节将详细阐述其核心数学推导与计算流程。

#### 2.1 判断矩阵的构造

在构建层次结构模型后，需采用 T.L. Saaty 提出的 $1-9$ 标度法，对同一层次内的各个元素针对上一层某一准则的相对重要性进行两两比较。

设待评估元素集合为 $E = \{e_1, e_2, ..., e_n\}$，通过成对比较构造出的判断矩阵记为 $A = (a_{ij})_{n \times n}$。其中，矩阵元 $a_{ij}$ 代表元素 $e_i$ 相对于元素 $e_j$ 的相对重要度量值。

**理论约束：**

为保证逻辑严密性，判断矩阵 $A$ 在数学上必须严格满足正反交替律（即正互反矩阵性质）：
$$
a_{ij} > 0, \quad a_{ji} = \frac{1}{a_{ij}}, \quad a_{ii} = 1 \quad (i, j = 1, 2, ..., n)
$$
**构造实例：**

假设在“外观配置”准则下比较三款备选机型 $P_1, P_2, P_3$。若决策者认为 $P_1$ 比 $P_2$ 稍微重要（标度为 $3$），$P_1$ 比 $P_3$ 明显重要（标度为 $5$），且 $P_2$ 比 $P_3$ 介于同等与稍重要之间（标度为 $2$），基于正互反律，该判定矩阵 $A$ 即可严格确立为：
$$
A = \begin{bmatrix} 1 & 3 & 5 \\ 1/3 & 1 & 2 \\ 1/5 & 1/2 & 1 \end{bmatrix}
$$


#### 2.2 层次单排序与权向量求解

层次单排序旨在计算本层各元素对上一层某一准则的相对重要性权重。其数学本质是求解正互反矩阵的最大特征值及其对应的归一化特征向量。

**数学推导：**

在理想状态下，若决策者的判断具有完全的逻辑传递性（即 $\forall i, j, k$，满足 $a_{ik} = a_{ij} \cdot a_{jk}$），判断矩阵 $A$ 为一致性矩阵。根据矩阵代数理论，此时存在唯一的非零特征向量 $\omega$，满足：

$$A \omega = n \omega$$

其中，$n$ 为矩阵的唯一非零特征值（也是最大特征值），$\omega$ 即为所求的精确权重向量。

然而，在实际决策环境中，由于人类主观认知存在模糊性与偏差，判断矩阵通常难以满足完全一致性条件。根据矩阵扰动理论，若矩阵 $A$ 发生微小摄动，其特征值亦发生微小变化。因此，实际计算中需通过求解矩阵 $A$ 的最大特征值 $\lambda_{max}$ 及其对应的特征向量 $W$ 来获得近似解析解：
$$
A W = \lambda_{max} W
$$
对方程解出的特征向量 $W = (w_1, w_2, ..., w_n)^T$ 进行列和归一化处理，所得向量即为当前层级下各元素的相对重要性权向量。

#### 2.3 一致性检验机制

为规避决策过程中可能出现的逻辑传递性断裂（例如：得出 $A \succ B$ 且 $B \succ C$，却反常态得出 $C \succ A$），必须对判断矩阵引入严格的一致性检验。

**检验指标与判定标准：**

1. **计算一致性指标（Consistency Index, CI）：**

   通过度量最大特征值 $\lambda_{max}$ 对理论值 $n$ 的偏离程度来反映矩阵的一致性水平：
   $$
   CI = \frac{\lambda_{max} - n}{n - 1}
   $$
   当矩阵具有完全一致性时，$\lambda_{max} = n$，此时 $CI = 0$。$CI$ 值越大，一致性越差。

2. **引入平均随机一致性指标（Random Index, RI）：**

   $RI$ 是基于蒙特卡洛模拟，通过构造大量随机正反矩阵所计算得出的 $CI$ 数学期望值。对于 $n=1$ 至 $9$ 阶矩阵，其对应的 $RI$ 常数取值分别为：$0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45$。

3. **计算一致性比例（Consistency Ratio, CR）：**
   $$
   CR = \frac{CI}{RI}
   $$
   **判别法则：** 设定检验阈值为 $0.10$。当且仅当 $CR < 0.10$ 时，判定判断矩阵通过一致性检验，其导出的权向量具有合理性；若 $CR \geq 0.10$，则需对矩阵元 $a_{ij}$ 进行重新评估与修正。

#### 2.4 层次总排序与最终决策

在各层级单排序完成且均通过一致性检验的基础上，需自上而下计算最底层（方案层）相对于最高层（目标层）的组合权重。

设准则层 $C$ 对目标层 $O$ 的权向量为 $W_c = (c_1, c_2, ..., c_m)^T$；方案层 $P$ 中各备选方案针对第 $j$ 个准则 $C_j$ 的单排序权向量为 $W_{pj} = (p_{1j}, p_{2j}, ..., p_{nj})^T$。基于线性加权求和模型，第 $i$ 个备选方案的综合评价得分 $Total_i$ 定义为：
$$
Total_i = \sum_{j=1}^{m} c_j \cdot p_{ij}
$$
依据综合得分降序排列，得分最高者即为全局最优决策方案。

function [weights, CR] = Calculate_AHP(A, matrix_name)
    n = size(A, 1);
    [V, D] = eig(A); 
    eigenvalues = diag(D); 
    [max_lambda, max_index] = max(real(eigenvalues)); 
    
    W = real(V(:, max_index)); 
    weights = W / sum(W);
    
    CI = (max_lambda - n) / (n - 1);
    RI_Table = [0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45];
    
    if n <= 2
        CR = 0; 
    else
        RI = RI_Table(n);
        CR = CI / RI;
    end
    
    fprintf('矩阵 [%s] 权重: ', matrix_name);
    fprintf('%.4f  ', weights);
    fprintf('| CR = %.4f ', CR);
    
    if CR < 0.1
        fprintf('(通过检验)\n');
    else
        fprintf('(警告: 未通过检验!)\n');
    end
end
