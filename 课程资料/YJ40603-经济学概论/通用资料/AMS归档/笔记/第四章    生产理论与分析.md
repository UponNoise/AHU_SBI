# 第四章    生产理论与分析

## 一、生产函数（Production Function）

### 1. 生产函数定义

生产函数表示：

> 在一定技术水平前提下，描述生产要素某种组合同它可能生产的最大产量间的关系 。
>
> 正常情况下，Q是$ x_i $的增函数

### 2. 基本公式

一般形式 ：$$Q = f(x_1, x_2, \cdots)$$

为简化起见，通常将所有的要素分为劳动（$L$）和资本（$K$）两大类 ：$$Q = f(K, L)$$

------

### 3. Cobb-Douglas 生产函数（重点）

一般形式（幂函数乘积） ：$$Q = A K^\alpha L^\beta \quad (0 < \alpha, \beta < 1)$$

### 经济含义：

- 正常情况下，$Q$ 是要素 $x_i$ 的增函数 
- 描述了最大可能的产出量 。
- 要素间存在替换与辅助关系，生产一定产量可用不同方法（替代性） 。

👉 **易错点提醒**：生产函数描述的是“最大”可能产量，而非实际随意组合的产量；其前提是“一定技术水平”，这是纯技术概念，无经济含义 。

### 4.几个重要关系重要关系

#### （一）替代性：

生产一定的产量可以用许多不同的方法

####   (二）如果要素投入量加倍，产量也加倍：规模收益

#### （三）如果其他要素不变，某要素单独变化, 产量随着发生变化：要素收益

# 二、用一个可变投入要素生产

### 1. 基本概念

- **可变要素（Variable input）**： 为增减产出数量，使用数量可调整的投入要素
- **固定要素（Fixed input）**：投入数量不随不同产出量变化的要素

- **短期（Short run）**：存在可变要素和固定要素的时期（至少有一种投入固定） 。
- **长期（Long run）**：所有投入要素都可变，无固定要素的时期 

有关产量三个核心概念 ：

- **总产量（TP, Total Production）**：$TP = Q$ 

- **平均产量（AP, Average Production）**：$AP = TP / x$ 

- **边际产量（MP, Marginal Production）**：连续型求极限下，$MP = dTP / dx$

## 2. 产量函数之间的相互联系（重点推导）

### （1）从  $TP $ 到 AP 和 MP

- 如果将 $TP $曲线上的某点与原点连线，则该连线的**斜率**即为 AP 。

-  $TP $曲线上各点的切线**斜率**即为 MP（$MP = \frac{dTP}{dL}$） 。

-  $TP $的二阶导数为零，此时 MP 最大 。

- **极大值点**： $TP $的一阶导数为零，此时 MP 为零 。

### （2）AP 与 MP 的关系

核心公式推导 ：
$$
\frac{dAP}{dL} = \frac{d\left(\frac{TP}{L}\right)}{dL} = \frac{1}{L} \left( \frac{dTP}{dL} - \frac{TP}{L} \right) = \frac{1}{L} (MP - AP)
$$

## 3. 生产的三阶段

> **边际收益递减规律**：当可变投入要素增加而其他要素固定时，总会达到一个点，在此之后可变要素的边际产量（$MP$）开始下降 。

<img src="C:\Users\lenovo\AppData\Roaming\Typora\typora-user-images\image-20260406022033194.png" alt="image-20260406022033194" style="zoom:50%;" />



- **第 Ⅰ 阶段（有待开发）**：$MP > 0$ 且 $AP$ 递增，此时 $MP > AP$。固定要素相对过多，增加可变要素能极大提高效率 。
- **第 Ⅱ 阶段（最佳生产区域）**：$AP$ 开始递减至 $MP = 0$。此时 $MP < AP$ 且 $MP > 0$。符合边际收益递减规律 。
- **第 Ⅲ 阶段（生产禁区）**：$MP < 0$。可变要素过多导致总产量 $TP$ 下降，生产效率低 。

## 4. 利润最大化条件（单要素）

- **边际产量收入（$MRPL$）**：增加一单位生产要素（$L$）所带来的总收入变化，$MRPL = \frac{dTR}{dL} = MR \cdot MP_L$ 。

- **最优条件**：使用追加的可变投入直到边际产量收入等于边际成本（工资率 $w$），即：$MRPL = w$ 或 $P \cdot MP_L = w$ 。

- ==**利润最大化条件**==     

   TR (Total Revenue，总收益) $TR = P \times Q$

  TC (Total Cost，总成本) $TC = FC + VC(Q)$

  MR (Marginal Revenue，边际收益) $MR = \frac{\Delta TR}{\Delta Q}$

  MC (Marginal Cost，边际成本) $MC = \frac{\Delta TC}{\Delta Q}$

  利润最大化必要条件：$MC=MR$

### 2. 边际技术替代率（$MRTS$）

描述了要素 $L$ 替换要素 $K$ 时的替代能力，是等产量曲线斜率的**负值** 。

$$MRTS_{LK} = - \frac{dK}{dL} = \frac{MP_L}{MP_K}$$

👉 **推导**：对 $Q = f(L, K)$ 求全微分 $dQ = MP_L dL + MP_K dK = 0$，整理即得 $MRTS_{LK}$ 。



### 3. 生产者均衡（重点计算）

### （1）等成本曲线方程

$$
C_0 = rK + wL \quad \Rightarrow \quad K = \frac{C_0}{r} - \frac{w}{r} L
$$

（斜率为 $-\frac{w}{r}$） 。



### （2）==高效率生产/均衡条件==

等产量曲线与等成本曲线**相切**，此时：
$$
MRTS_{LK} = \frac{MP_L}{MP_K} = \frac{w}{r} \quad \Rightarrow \quad \frac{MP_L}{w} = \frac{MP_K}{r}
$$
经济含义：花费在每种要素上的最后一单位成本所带来的边际产量必须相等 。 

（注：==高效率生产是利润最大化的必要而非充分条件== ）。

### （3）生产扩大路线 (Expansion path in production )

​        **扩大路线**：满足高效率生产条件$$\frac{MP_L}{w} = \frac{MP_K}{r}$$的K−L组合的集合

## 四、规模经济性与范围经济性

### 1. 规模经济性判定法则

已知生产函数 $Q = f(K, L)$，当所有要素投入量扩大 $\lambda$ 倍，导致产量扩大 $h$ 倍（$hQ = f(\lambda K, \lambda L)$）时 ：

- $h = \lambda$：规模收益不变 
- $h < \lambda$：规模收益递减 
- $h > \lambda$：规模收益递增 

👉 **C-D函数捷径**：对于 $Q = A K^\alpha L^\beta$，直接比较规模收益系数 $(\alpha + \beta)$ 与 $1$ 的大小 。

- $\alpha + \beta > 1$ $\rightarrow$ 递增 
- $\alpha + \beta < 1$ $\rightarrow$ 递减 
- $\alpha + \beta = 1$ $\rightarrow$ 不变 

### 2. 范围经济性 (Economies of scope)

度量企业多商品组合生产是否降低平均成本 。

$$S = \frac{TC(Q_A) + TC(Q_B) - TC(Q_A, Q_B)}{TC(Q_A, Q_B)}$$

$S > 0$ 代表存在范围经济性 。
