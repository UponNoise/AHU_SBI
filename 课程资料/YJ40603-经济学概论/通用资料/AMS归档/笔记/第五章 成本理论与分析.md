# 第五章 成本理论与分析

## 一、成本的经济概念

### 1. 成本定义

- **外显成本（Explicit cost）**：指对另一方的实际支付 。
- **内含成本（Implicit cost）**：指放弃的机会的价值，不涉及实际的现金支付 。
- **沉没成本（Sunk Cost）**：过去已经支出的费用，或根据协议将来必须支出的费用 。
- **增量成本**：一项决策变化引起的成本变化（增加），它既可以是固定成本也可以是变动成本 。

👉 **易错点提醒**：

1. 依靠历史成本而不是机会成本会导致决策的失误 。
2. 沉没成本与当前决策无关，不应纳入决策权衡范围 。

### 2. 经济利润与会计利润（重点概念）

- **会计利润**：$$会计利润 = 总收益 - 外显成本$$。
- **经济利润**：$$经济利润 = 总收益 - 总成本 = 总收益 - 外显成本 - 内含成本$$。
- **正常利润**：对管理部门或资本的正常回报，是防止这些资源向其他企业或行业转移所必须的最低限度的支付 。正常利润等于内含成本（经营者自身投入要素的代价） 。

## 二、短期成本函数

### 1. 基本概念

- **短期**：在短期内，至少一个生产要素是固定的 。“短期”内存在固定投入，其相应成本即为固定成本，固定成本属于沉没成本 。

- **总成本（TC）**：$$TC = TVC + TFC$$。

  - 总变动成本（TVC）：随产量 $Q$ 的变化而变化 。
  - 总固定成本（TFC）：为常数，不随 $Q$ 变化 。

### 2. 平均成本与边际成本

- **平均总成本（AC）**：$$AC = \frac{TC}{Q}$$。
- **平均变动成本（AVC）**：$$AVC = \frac{TVC}{Q}$$。
- **平均固定成本（AFC）**：$$AFC = \frac{TFC}{Q}$$。
- **边际成本（MC）**：$$MC = \frac{dTC}{dQ} = \frac{dTVC}{dQ}$$。

### 3. 成本曲线间的相对位置（重点推导）

👉 **Step-by-step 结论**：

1. **AVC 与 AC 的极小值**：AVC 的最低点（$Q_1$）先于 AC 的最低点（$Q_2$）达到，即 $Q_1 < Q_2$ 。

2. **MC 与 AC 的数学关系**：

   - 当 $AC$ 下降时（$\frac{dAC}{dQ} < 0$），$$MC < AC$$。
   - 当 $AC$ 上升时（$\frac{dAC}{dQ} > 0$），$$MC > AC$$。
   - 当 $AC$ 达到极小值时（$\frac{dAC}{dQ} = 0$），$$MC = AC$$。

3. **几何表现**：MC 曲线依次由下而上穿过 AVC 和 AC 的最低点 。

## 三、长期成本函数

### 1. 长期成本的概念

- 在长期，所有投入要素皆可变 。
- **规模收益**：规模收益递增、递减、不变分别对应不同的成本函数特征 。现实中的企业多呈现先收益递增、后收益递减的长期成本函数 。

### 2. 长期平均成本曲线（LAC）

- 长期平均成本曲线（LAC）是无数条短期平均成本曲线（SAC）的外包曲线（包络曲线） 。

- 生产者从一个个短期成本曲线中寻求长期最佳点，LAC 一定小于等于短期成本 。

- **最适度生产规模**：当 LAC 极小时，它与某 SAC 的极小点相切，此时满足：

  ​                               $$LAC = SAC = LMC = SMC$$

## 四、成本理论专题

### 1. 利润贡献分析法

- **利润贡献**：$$Profit\ Contribution = P - AVC$$。

- 其经济学意义是，单位销售收入在补偿变动成本之后对利润的贡献额度 。

- **盈亏平衡点（Break Even Point）**： 若设定的目标利润为 $\pi_R$，则实现该利润需要的产量为 

  $$Q_R = \frac{FC + \pi_R}{P - AVC}$$。 当经济利润 $\pi_R = 0$ 时，对应的盈亏平衡产量为 $$Q_e = \frac{FC}{P - AVC}$$。

### 2. 经营杠杆（Operating Leverage）

- 如果固定成本相对变动成本较大，则企业的杠杆作用大。经营杠杆衡量的是固定成本的存在使得产（销）量的增加对利润增量的杠杆放大效应 。

- **利润弹性（$E_\pi$）**：

  $$E_\pi = \frac{\Delta \pi / \pi}{\Delta Q / Q} = \frac{Q(P - AVC)}{Q(P - AVC) - TFC}$$

👉 **Step-by-step 结论**：

1. 给定条件下，总固定成本（TFC）越大，企业的利润弹性 $E_\pi$ 值越大（风险越大，杠杆作用越明显） 。
2. 若单位利润贡献 $(P - AVC) > 0$ 且 TFC 给定，随着产量 $Q$ 的增大，$E_\pi$ 值会相应减小 。
